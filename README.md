# Portfolio Project

The complete system behind [Nicole Telesz's portfolio](https://www.nicoletelesz.com/), the research, the structure, and the real decision history, documented the whole way through.

This repo isn't just source files for a website. It's the actual working archive behind every case study on the site, including the case study about building this exact system. If you're here from **[Behind the Portfolio](https://www.nicoletelesz.com/portfolio)**, this is the "behind the scenes" the link promised.

---

## What's actually in here

| Folder | What it holds |
|---|---|
| `00_START_HERE/` | The foundational documents: a running decision log (thousands of real entries), a design manifesto, and the open questions that shaped the whole project |
| `01_Me/` | Resume, professional profile, and real interview-ready stories |
| `02_Portfolio/` | The site's own blueprint, information architecture, and product vision |
| `03_Case Studies/` | Every real project, including the one about this system itself |
| `04_Research/` | The actual research that informed the site's structure, visual direction, and content strategy, seven real topics deep |
| `05_Assets/` | Wireframes (low-fi through high-fi) and brand assets |
| `06_AI/` | Reserved for future AI-tooling documentation, not yet built out |

## How each case study is built

Every project in `03_Case Studies/` follows the same real workflow: raw research and materials first, then structured drafting through a set of guided content files, then a final, clean copy ready to paste into the live site. Each one also keeps its own full revision history, not just the finished result, so the actual thinking behind every decision stays visible, not just the outcome.

## What's intentionally not here

Each case study folder normally includes a `00_Raw/` directory, the actual working materials behind that project. Those folders exist locally but are deliberately excluded from this public repo. Some of that material is under NDA. Some of it is real research participant data that was never meant to be public. The finished, curated output of that work, the actual case study content and selected images, is fully here. The raw materials behind it aren't, on purpose.
