# Site Assets

Companion to `02_Portfolio/SEO Page Descriptions.md`, which covers the text half of "how the site looks when shared" (search results, link previews); this folder covers the visual half.

- **`Nt_app_icon.png`** — app icon / favicon.
- **`Nt_black.png`**, **`Nt_white.png`** — logo lockup, black and white variants (light/dark background use).
