From the Decision Log

Demonstrates UX thinking through the portfolio itself, encourages a structured process, and makes future decisions more consistent.

"The variations you gave me weren't very varied. It was the same layout and design presented three times. This was a bit of a disappointment." A real process correction, not just a concept discard — single-variable comparison is useful for resolving one specific question, but it's the wrong method when the goal is generating real options to choose from.

A divider line that violated the homepage's own no-dividers rule, a mismatched card size, an inconsistent breakpoint, and a missing flex property — all "good catches," all fixed before promotion rather than left for later.

A tag component was reused by name but quietly given different styling for a new purpose — so nothing named "engagement tag" on the page actually looked like one. Fixed by splitting it into two honestly-named components instead of one overloaded one.
