## Hero visual: final concept (locked 2026-10-01)
A single composition, not separate card/hero images: the actual live Homepage shown mid-construction on a laptop, with real floating elements (a tool-logo constellation plus the camera and glasses already used elsewhere on the Homepage) all carrying a unified "still being placed" treatment — selection handles (corner markers) and a motion/blur trail, applied consistently across every element including the laptop itself, not just the small icons. A mid-word typing cursor in the headline text reinforces the in-progress feeling without needing actual motion.

**Claude is deliberately not represented as its own element in the final version.** Three concept directions were explored (a matching floating app icon, a code-window icon suggesting Claude Code specifically, an active cursor with a label) — Claude's own recommendation was the matching icon option, for visual consistency with the Figma treatment. Nicole reviewed all three and decided to leave Claude out of the hero for now, keeping the composition as laptop + camera + Figma icon + glasses, all unified.

**Full concept evolution**, for reference: the project card (built first, per the deliberate ordering decision) showed the finished live site on a laptop with a tool-logo constellation in the background. The hero then evolved this into something genuinely different rather than a near-duplicate: instead of a finished state, it shows active construction, with every element (not just small icons) carrying the same "in progress" treatment.
