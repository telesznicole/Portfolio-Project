# Portfolio Project

Welcome to my portfolio repository.

This repository is the source of truth for the design, research, and development of my UX/Product Design portfolio. The portfolio itself is being treated as a product and developed using a research-driven, AI-assisted design process.

The goal is not simply to create a website, but to create an experience that demonstrates how I think as a designer.

---

# Start Here

If you're assisting with this project (human or AI), begin with these documents in order:

1. `00_START_HERE/Portfolio Manifesto.md`
2. `00_START_HERE/Portfolio Decision Log.md`
3. `01_Me/Professional Profile.md`
4. `02_Portfolio/Product Vision.md`

These documents define the project's goals, philosophy, constraints, and long-term direction.

---

# Repository Structure

## 00_START_HERE

Foundational documents that guide every major decision throughout the project.

## 01_Me

Information about me as a designer, including my professional profile, resume, interview stories, and other personal reference materials.

## 02_Portfolio

Product planning for the portfolio itself, including information architecture, design principles, writing, motion, and future documentation.

## 03_Case Studies

Research, assets, writing, and supporting materials for individual portfolio projects.

## 04_Research

Research that informs portfolio decisions, including:

- audience research
- hiring expectations
- competitive analysis
- portfolio strategy
- AI workflow research
- design inspiration and observations

This folder should be treated as evidence rather than final decisions.

## 05_Assets

Shared assets used throughout the portfolio.

## 06_AI

Prompts, experiments, reusable AI resources, and other supporting materials.

---

# Guiding Principles

- The portfolio is treated as a product.
- Research informs decisions.
- Evidence is preferred over assumptions.
- The repository is the single source of truth.
- AI is a collaborator, not the creative director.
- Final decisions always remain mine.

---

# Expectations for AI

When assisting with this project:

- Read existing documents before generating new work.
- Reuse existing decisions instead of creating conflicting ones.
- Present multiple thoughtful options when making significant design recommendations.
- Challenge ideas when there is a strong design rationale for doing so.
