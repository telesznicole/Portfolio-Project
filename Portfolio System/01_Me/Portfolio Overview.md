# FEATURED PROJECTS

## Feminist UX — MFA Thesis Project

Project Type:
Independent thesis / research-driven design project

Overview:
My thesis, Feminist UX, proposes a framework for designing with power, participation, and exclusion in mind — moving beyond surface-level "inclusion" toward more critical, equity-centered design practice. I built a companion site (feministux.org) to bring the research beyond academia, focusing on a learn, experience, engage experience where the user can learn about the foundations and definition of Feminist UX, experience contrasting flows of Anti-Feminist UX and Feminist UX through a simulated on-boarding experience for an embodied understanding, and engage in the principles of Feminist UX through a questionnaire toolkit that allows them to measure their work against its prinicples and receive personalized feedback.

My Role:
UX Designer, Interaction Designer, Researcher, Developer

Problem / Opportunity:
An increasingly "check-list" approach to inclusivity and human-centeredness in design

Solution:
A microsite embodying Feminist UX as an established framework alongside interactive tools for better understanding and engaging with it

Key Contributions:
- Framework creation
- User collaboration and research
- Highly interactive website development

Skills Demonstrated:
- UX research
- Interaction design
- Framework development
- Prototyping
- Front-end development
- Inclusive design

Why This Project Matters:
This project highlights my ethos and deeply committed approach to truly human-centered design beyond just surface-level committment. It also highlights my systems thinking and product design across both framework and engaging product development.

My Role:

Solution:
*The solution is under NDA, although an abstracted description has been created but cannot be shared publically* A new ecosystem utilizing Meta AI that would allow users to create custom and sharable applications through the glasses for increased connectivity and integrating into their lives
